## 本地预览

直接打开 `index.html`，或在仓库目录运行以下命令。

```powershell
python -m http.server 4183 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:4183/`。页面、图片和视频都从本地加载。
