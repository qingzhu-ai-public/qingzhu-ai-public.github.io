# 青竹 AI 品牌官网

青竹 AI 的品牌介绍、专家与技能目录。

网站地址：https://qingzhu-ai-public.github.io/

## 本地预览

```sh
python -m http.server 4173
```

## 维护

- `index.html`：品牌内容与页面结构。
- `styles.css`：视觉设计与手机布局。
- `app.js`：产品目录、搜索、分类筛选与详情。
- `assets/`：品牌素材。

更新产品时，编辑 `app.js` 中的 `products` 数组。当前包含天赋发现专家与其 5 个内置技能；专家标记为即将上线，未使用虚构的购买链接。

推送至 `main` 分支后，GitHub Pages 自动发布。

品牌标识与网站内容归青竹 AI 所有。
